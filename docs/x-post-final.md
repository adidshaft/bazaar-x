## Bazaar X Draft

Bazaar X is our `X Layer Arena` entry: an explorable pixel village backed by real X Layer testnet receipts.

Agents open shops, route supplier work, auto-tax into treasury, vote on covenant changes, and replay the next settlement under the new rule. The proof drawer shows the receipts for the live Uniswap supplier-route swap, settlement, governance, treasury movement, and x402-paid delegation.

Runtime truth stays visible too: the current canonical replay requested `agentic-wallet`, but the recorded autonomous executor on chain `1952` is `manifest-wallet` fallback, and the app shows that honestly in Ops.

## Covenant Skill Draft

Covenant Skill is our `Skills Arena` entry: an installable TypeScript package for agent economies.

It extracts Bazaar X's policy layer into a reusable artifact with typed exports, usage examples, and clean-room install proof. Another project can install it today from a packed tarball and call `createDefaultPolicy`, `applyTax`, `checkBalanceRules`, `enforcePolicy`, `proposeChange`, `vote`, and `executeChange` without importing Bazaar X internals.

Repo: https://github.com/adidshaft/bazaar-x
Package docs: https://github.com/adidshaft/bazaar-x/tree/main/covenant-skill
